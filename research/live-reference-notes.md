# Live NearFlux reference notes

Visited: https://near-flux-online.onrender.com/

The live site redirects/opens with a URL query parameter in the form `?room=FLUX-3796`, showing a generated room code. On first load it presents an `Identify Your Device` modal with a device-name input, `Save & Continue`, and `Use Default Name`. After dismissing the modal, the main interface contains:

- Header: NearFlux branding, Online status, a room pill `Room: FLUX-3796`, editable device badge, help button, and theme toggle.
- Upload area: `Drag & Drop Files or Folders Here`, supporting single files, multiple files, and nested folder structures, with `Select Files` and `Select Folder` buttons.
- Room section: `Devices in Private Room`, a room-code badge, copy explaining that only devices with the secret code are visible, a waiting message, and `Copy Share Link` / `Show QR Code` actions.
- Footer: About, How to Use, Privacy Policy, FAQ, Contact, Support Developer, and `© 2026 NearFlux Online — Fast, Private Worldwide P2P Transfers`.

The live reference confirms the intended flow is a secret room identified by a query parameter and shared with another user through a link or QR code. The target is therefore a real room-based internet sharing feature, not only a visual restyle.
